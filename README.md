# ArchitectureBattle

Minecraft JE Server & Client Side Fabric Mod

建築練習等に役立つと嬉しいです⛏

[Modrinth](https://modrinth.com/mod/architecturebattle)

## Usage/使い方

### theme command / テーマコマンド
```
/theme <> <> ...
```

### timer command / タイマーコマンド
```
/timer <minutes>
```
pause / 一時停止
```
/timer stop
```
resume / 再開
```
/timer start
```

## 対応バージョン

- Minecraft 1.21 - 1.21.x
